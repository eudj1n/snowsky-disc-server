# The pictures

`readme-*.jpg` are the README's pictures of the application manager. They
were taken on 2026-10-08 from the disposable test player
([development](../development.md#disposable-guest)): snowsky-disc-qemu's
emulator at `f1d5e33` running FiiO's firmware 2.57 with the boot layer's image
of the owner's player, server 2.57.4 installed by the boot layer, updated to
2.57.5 through this manager, Disc Player 1.0.0 installed through it from its
published zip, then the guest started again as usual (the boot layer "by
default"). The address the manager shows is the guest's loopback; on a player
it is the player's own. The guest's serial number is synthetic; none is
shown.

Chromium through Playwright took them: the desktop at 1280 px wide with twice
the pixels, the whole page, light and dark, and the first screen on a Pixel 7
phone, written as JPEG. Nothing is retouched or composited afterwards.

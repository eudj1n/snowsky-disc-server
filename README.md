# SNOWSKY DISC server

An unofficial service for the SNOWSKY DISC player, not affiliated with FiiO
or SNOWSKY. It runs on the player next to its own software and lets a browser
page (Disc Player) browse the collection, control playback, keep play history
and playlists, and manage the files on the card — over the player's Wi-Fi,
with every change confirmed by the player itself.

**Status: in development.** It will be installed as a package of the DISC boot
layer; there is nothing to install yet.
